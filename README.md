# E-Commerce Funnel, Root Cause & A/B Test Analysis (Python)

## Project Overview

This project analyzes session-level behavior in a simulated e-commerce journey to answer three practical questions:

1. **Where are users dropping out of the funnel?**
2. **Which segments appear to contribute to the cart-to-checkout problem?**
3. **Does a simplified checkout experience improve checkout-to-order conversion?**

The project moves from descriptive funnel analysis to diagnostic segmentation and finally to a randomized A/B test.

The analysis is implemented in Python using **pandas, NumPy, Matplotlib, and SciPy**.

> **Related project:** My [E-Commerce SQL Business Analysis](https://github.com/SiddharthSinghJadon/ecommerce-sql-business-analysis) focuses on marketplace-level KPIs using the Olist dataset. This project takes a different approach by focusing on session-level behavior, funnel conversion, segmentation, and experimentation.

---

## Business Problem

An e-commerce team wants to improve conversion from an app session to a completed order.

Rather than looking only at overall conversion, the analysis breaks the customer journey into stages:

```text
App Open
   ↓
Search
   ↓
Product View
   ↓
Add to Cart
   ↓
Checkout
   ↓
Order Placed
```

The goal is to identify the most important funnel drop-offs, investigate whether the cart-to-checkout drop is concentrated in particular segments, and evaluate a proposed checkout redesign using an A/B test.

# 1. Funnel Analysis

The first step is to calculate the number of sessions reaching each stage and the conversion between consecutive stages.

| Stage | Sessions | Step Conversion |
|---|---:|---:|
| App Open | 52,000 | — |
| Search | 37,415 | 72.0% |
| Product View | 24,987 | 66.8% |
| Add to Cart | 8,453 | 33.8% |
| Checkout | 3,764 | 44.5% |
| Order Placed | 2,974 | 79.0% |

**Overall App Open → Order conversion: 5.72%**

![E-Commerce Funnel](charts/1_funnel.png)

### Finding

The largest percentage-point drop occurs between **Product View → Add to Cart**, where conversion falls from 66.8% to 33.8%.

The **Cart → Checkout** stage is also notable because only 44.5% of sessions that added an item reached checkout.

Because users who have already added an item have demonstrated stronger purchase intent, this stage was selected for deeper diagnostic analysis.

---

# 2. Root Cause Analysis: Cart → Checkout

A single overall conversion rate can hide important differences between user segments.

The carted sessions were therefore segmented by:

- Device
- Time of day

![RCA Segmentation](charts/2_rca_segments.png)

### Device

| Device | Cart → Checkout Conversion |
|---|---:|
| Mobile | 39.0% |
| Tablet | 48.7% |
| Desktop | 55.2% |

### Time of day

| Segment | Cart → Checkout Conversion |
|---|---:|
| Late night (11pm–5am) | 39.4% |
| Rest of day | 45.0% |

### Statistical validation

The mobile and desktop groups were compared using a **two-proportion z-test**.

```text
Mobile:   39.0%
Desktop:  55.2%

z = -13.42
p < 0.0001
```

The large difference and very small p-value indicate that the observed mobile/desktop gap is unlikely to be explained by sampling variation alone.

### Interpretation

Mobile sessions show substantially lower cart-to-checkout conversion than desktop sessions, while mobile also represents the majority of traffic.

This makes mobile checkout a strong **diagnostic signal and optimization hypothesis**.

However, this segmentation is observational. It does **not by itself prove that the device or mobile interface caused the lower conversion**.

The appropriate next step is therefore experimentation rather than treating the segmentation result as definitive causal evidence.

---

# 3. A/B Test: Simplified Checkout

Based on the diagnostic analysis, the project evaluates a proposed checkout change.

### Hypothesis

> A simplified one-page checkout experience will increase checkout-to-order conversion compared with the existing multi-step checkout.

### Experiment design

Users were randomly assigned to:

- **Control:** existing multi-step checkout
- **Treatment:** simplified one-page checkout

The primary metric is:

```text
Checkout → Order Conversion
```

A two-proportion z-test is used to compare the conversion rates.

![A/B Test](charts/3_ab_test.png)

### Results

| Arm | Conversion | Users |
|---|---:|---:|
| Control | 79.60% | 4,515 |
| Treatment | 84.91% | 4,485 |

### Lift

**Absolute lift**

```text
84.91% - 79.60%
= +5.30 percentage points
```

**Relative lift**

```text
(84.91% - 79.60%) / 79.60%
≈ +6.7%
```

### Statistical result

```text
z = 6.58
p < 0.0001
```

The treatment group has a higher observed conversion rate, and the statistical test provides strong evidence against the null hypothesis of equal conversion rates.

### Recommendation

Within this simulated experiment, the one-page checkout performs better than the existing multi-step checkout.

A practical next step would be to validate the change further across important user segments and monitor downstream business metrics before treating the result as a production decision.

# Limitations

This project is intended as a portfolio analytics exercise, so several limitations should be kept in mind:

1. **Synthetic data** — results do not represent a real business or real customer behavior.
2. **RCA is observational** — the device-level difference identifies a strong segment-level signal but does not independently establish causality.
3. **A/B test assumptions** — the simulated experiment assumes randomized assignment and a clean conversion outcome.
4. **Limited segmentation** — only device and time of day are explored in the RCA.
5. **No downstream business metrics** — revenue, margin, refunds, and long-term retention are outside the scope of this analysis.
6. **No production experiment concerns** — real experimentation would also require checks such as experiment duration, sample-ratio mismatch, guardrail metrics, and potential segment-level effects.

# Key Takeaways

The analysis illustrates how a product analytics investigation can progress from a broad funnel problem to a more focused experiment:

- Overall App Open → Order conversion was **5.72%**.
- Product View → Add to Cart was the largest percentage-point funnel drop.
- Mobile users showed a substantially lower Cart → Checkout conversion than desktop users.
- The mobile/desktop difference was statistically significant in the simulated data.
- A simulated one-page checkout produced a **5.30 percentage-point** improvement in Checkout → Order conversion.
- The A/B test result was statistically significant in the simulated experiment.
- The segmentation analysis provides a hypothesis; the randomized experiment provides stronger evidence for evaluating the proposed checkout change.
